MINAS NUMERICAS - 32 metodos numericos (segun tus apuntes en PDF)
==================================================================
COMO EJECUTAR (Windows)
 1) Python 3.9 o superior (python.org, marca "Add Python to PATH").
 2) En una terminal dentro de esta carpeta:
        python -m pip install pygame-ce     (o pygame, si te instala bien)
        python main.py
    (Si pip no se reconoce:  python -m pip install pygame)

COMO SE JUEGA
 - Empiezas con los 5 metodos de Interpolacion (rareza Comun).
 - Elige un metodo y resuelve cada paso (3 fusibles). Enter = enviar, F1 = formula, Esc = salir.
 - Aceptan 0.001 de diferencia (o 0.1 %), asi que puedes redondear a 3-4 decimales.
 - Al completar un metodo puede desbloquearse otro cualquiera. Mientras mas dificil la
   seccion completada, mas probabilidad de premio y mas chance de rarezas altas.
 - Rarezas: Interpolacion=Comun, Minimos cuadrados=Poco comun, Lineales=Raro,
   Integracion=Epico, No lineales=Legendario, EDO=Mitico.
 - Boton COLECCION: todo lo desbloqueado y cuantas veces completaste cada metodo.
 - Boton PARTIDAS (menu principal): hasta 5 ranuras de guardado.
     CARGAR / NUEVA (ranura vacia) / GUARDAR (copia tu avance actual ahi) / BORRAR.
     Sobrescribir o borrar pide una segunda pulsacion (CONFIRMA).
 - Autoguardado: al ganar un metodo se guarda en tu ranura actual (o en la primera libre).
   Al abrir el juego se carga la ultima ranura usada.
 - Las partidas viven en la carpeta "partidas" (partida_1.json ... partida_5.json).
   Para reiniciar todo, borra esa carpeta. Si tenias partida.json de la version anterior,
   se pasa sola a la ranura 1.

ARCHIVOS: main.py (ventana) / logica.py (reglas) / metodos.py (los 32 métodos)
